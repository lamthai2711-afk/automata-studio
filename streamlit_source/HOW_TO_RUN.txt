========================================================================
AUTOMATA STUDIO - OFFLINE & ONLINE QUICK START GUIDE
========================================================================

This package includes two 100% synchronized offline-ready editions of
Automata Studio (Lecture 5 Slides 99-132 Edition + Single-Checkbox
Optional DFA Minimization Extension):
  1. Zero-Install Offline Web App: double-click "index.html" (no Python or internet needed!)
  2. Double-Click Python Streamlit App: "Start_Automata_Studio.bat" / ".command" / ".sh"

Tip: Leave "Extension: DFA Minimization" unchecked for the pure 4/5-step
Lecture 5 NFA -> DFA workflow, or tick that single checkbox anytime to unlock
step-by-step group-by-group DFA minimization!

------------------------------------------------------------------------
OPTION 1: ZERO-INSTALL 100% OFFLINE WEB APP (FASTEST FOR STUDENTS)
------------------------------------------------------------------------
1. Extract (Unzip) this folder completely.
2. Double-click "index.html" to open Automata Studio in Chrome, Edge,
   Firefox, or Safari -- works 100% offline with zero internet connection!
   ("stable.html" is also included as the classic reference layout.)

------------------------------------------------------------------------
OPTION 2: UNZIP & DOUBLE-CLICK STREAMLIT DESKTOP APP (PYTHON EDITION)
------------------------------------------------------------------------
Prerequisite: Python 3.9+ installed (https://www.python.org/downloads/ --
on Windows, check "Add python.exe to PATH" during installation).

1. Extract (Unzip) the downloaded ZIP folder completely.
2. Double-click the launcher for your OS:
   - Windows : Double-click "Start_Automata_Studio.bat"
   - macOS   : Double-click "Start_Automata_Studio.command" (Right-click -> Open first time)
   - Linux   : Run "./start_automata_studio.sh"

First run creates a local ".venv" and installs Streamlit, Graphviz, and Pandas
(requires internet once). Every run after that works 100% offline and opens
http://localhost:8501 in seconds!
