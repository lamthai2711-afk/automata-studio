# Automata Studio: Interactive NFA → DFA → Minimized DFA Learning Lab

Interactive educational web application for **Formal Languages and Automata Theory** at **Széchenyi István University (SZE)**.

## Repository Structure
- `index.html`: Standalone interactive web application for GitHub Pages (`NFA → DFA Subset Construction`, `E-Closure (E-sets)`, `Moore Equivalence Partitioning`, and `Step-by-Step String Stepper`).
- `streamlit_source/`:
  - `NFA.py`: Original Python Streamlit source code.
  - `requirements.txt`: Python dependencies (`streamlit`, `graphviz`, `pandas`).
  - `packages.txt`: System dependency (`graphviz`).
